Flight Telemetry & Aircraft Movement Analysis is a Python-based data analytics project focused on exploring aircraft surveillance data using Pandas, NumPy, Matplotlib, Seaborn, and Plotly. The project involves data cleaning, missing-value assessment, data validation, feature engineering, and exploratory data analysis of aircraft speed, altitude, flight status, and geographical positions. It also explores flight-phase classification, range-based filtering, moving-average smoothing, and coordinate-based distance calculations. The objective is to extract meaningful insights from flight data, assess data quality, and understand aircraft movement patterns while developing practical analytical skills relevant to aviation, flight telemetry, and aerospace data analytics.
